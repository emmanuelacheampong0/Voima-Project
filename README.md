# Voima — Sickle Cell Advocacy, Design & Digital Health

**Connecting sickle cell advocacy with technology through brand design, product communication, and community engagement.**

Voima is a youth-led initiative working across sickle cell education, advocacy, research, community engagement, and digital health. This repository presents my work as **Social Media & Engagement Lead**, helping make its mission recognizable, its health information accessible, and its emerging app understandable to potential users.

My contribution connected brand strategy with practical execution: a consistent visual identity, educational and fundraising campaigns, and launch materials that helped people understand how technology could support everyday sickle cell management.

## Explore the project

The portfolio in [`index.html`](index.html) walks through the challenge, my role, selected creative work, engagement snapshots, and lessons learned. It includes:

- **Brand system:** a documented 15-page guide covering logo use, colors, typography, imagery, voice, applications, governance, and marketing, with selected brand visuals shown in the case study.
- **Product communication:** app onboarding creative and launch messaging explaining daily check-ins, symptom patterns, tailored guidance, and community support; promotion of the early-user test program and waitlist.
- **Campaign design:** sickle cell education, World Blood Donor Day awareness, and Giving Month fundraising materials.
- **Engagement analysis:** platform analytics used to understand audience reach and guide content decisions.

**Repository scope:** a static portfolio case study documenting my brand, engagement, and product communication contributions. The Voima App appears through mockups and launch materials; its application code and health-management features are outside this repository.

## Technologies

| Technology | Use |
| --- | --- |
| HTML5 | Semantic page structure and case-study content |
| CSS3 | Custom properties, responsive grids, light/dark color schemes, and animations |
| Vanilla JavaScript | Scroll-triggered reveals using `IntersectionObserver`, with a reduced-motion preference check |
| Embedded JPEG images | Six portfolio visuals stored as base64 data URLs within the HTML |
| Google Fonts | IBM Plex Sans and Source Serif 4, with system-font fallbacks |

The page runs directly in a browser, with no package installation, build step, API keys, or backend setup. Google Fonts requires an internet connection; the embedded images are included in the file.

## Run locally

```bash
git clone https://github.com/emmanuelacheampong0/Voima-Project.git
cd Voima-Project
```

Open `index.html` in a modern browser. Alternatively, with Python 3 installed:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000). Stop the server with `Ctrl+C`.
